| R1  | Использование технологий с существующей экспертизой в банке                                                                                      | .NET, Java, Oracle, MS SQL, PostgreSQL                                           |

| +S  | + Безопасность (Security)                                                                                                                        |                                                                                  |
| SY1 | Обеспечить шифрование трафика между клиентом (сайт) и серверов                                                                                   |                                                                                  |
