# Задачи
1. Разработка сервиса управления депозитами:
	* обработка заявки на открытие депозита;
    * обработка ставок от монолита АБС и передача в кол-центры;
2. Доработка сайта:
   * отображение депозитных ставок;
   * проксирование заявки в сервис управления депозитами;
3. Доработка интернет банка:
    * отображение персонализированных депозитных ставок;
    * проксирование заявки в сервис управления депозитами;
4. Доработка системы кол-центра для получения/отображения ставок по депозиту и обработки заявок на открытие депозита
5. Доработка системы партнерского кол-центра для получения/отображения ставок по депозиту
6. Отладка интеграций - комплексное тестирование
7. Развертывание на контуре промышленной эксплуатации
