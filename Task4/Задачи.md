# Задачи

1. Доработка "АБС" в части:
    * разработка формы загрузки актуальных депозитных ставок;
    * перенаправление файла с актуальными ставками к "Сервису управления депозитами";
    * доработка "Сервису управления депозитами" в части добавления функциональности рассылки файлов кол центрам:
        * "Системе кол-центра" - по HTTP;
        * "Системе партнерского кол-центра" посредством сетевого файлового хранилища.
2. Доработка системы кол-центра в части:
    * получение файла со ставками по депозиту по протоколу HTTP;
    * отображение файла со ставками по депозиту менеджерам кол-центра.
3. Доработка "Системы партнерского кол-центра" в части:
    * получение файла со ставками по депозиту по протоколу HTTP;
    * отображение файла со ставками по депозиту менеджерам кол-центра
4. Создание файлового хранилища и настройка доступа системы "АБС" и "Системы партнерского кол-центра"
